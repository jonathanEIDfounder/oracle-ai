## Generate the model

On a macOS machine with Python 3.10+:

```bash
# Install dependencies
pip install coremltools scikit-learn numpy

# Train and compile
python3 scripts/train-behavioral-encoder.py
```

This runs in ~30 seconds and produces both the `.mlpackage` and the compiled `.mlmodelc` in this directory.

---

## Add to the Xcode project

1. Open `Oracle-AI.xcodeproj` in Xcode
2. In the Project Navigator, right-click `AARTE-iOS-App/Resources/`
3. Choose **Add Files to "Oracle-AI"…**
4. Select `BehavioralEncoder.mlmodelc`
5. Ensure **Target: OracleAI** is checked → **Add**
6. Confirm it appears in **Build Phases → Copy Bundle Resources**

> The `project.yml` already lists this path as an optional resource, so
> XcodeGen will include it automatically once the file exists.

## How AIEngine uses the model

```swift
// AIEngine.swift — loadModelIfAvailable()
let cfg = MLModelConfiguration()
cfg.computeUnits = .cpuAndNeuralEngine   // ← routes to A12 Neural Engine
mlModel = try MLModel(contentsOf: url, configuration: cfg)
```

When the model bundle is present, `AIEngine.embed()` logs:
```
[AARTE] Inference path: Neural Engine (BehavioralEncoder.mlmodelc)
```

When absent, it falls back to the Hadamard heuristic and logs:
```
[AARTE] Inference path: Heuristic (no model bundle)
```

| Trigger | Action |

| 30 days elapsed | Re-run `train-behavioral-encoder.py` |

## Model specification

| Property | Value |
|----------|-------|
| Input | `input` — Float32 MultiArray `[24]` |
| Output | `embedding` — Float32 MultiArray `[24]` (L2-normalised) |
| Architecture | MLP: 24 → 128 → 64 → 32 → 24 (tanh activations) |
| Training | Autoencoder on synthetic behavioral clusters |
| Compute | `.cpuAndNeuralEngine` — A12 NE accelerated |
